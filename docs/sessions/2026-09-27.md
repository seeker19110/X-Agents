## Hook auto-format chỉ format file vốn sạch (#364)

- Bẫy đã vào nhật ký năm lần (2026-09-22, 09-23, 09-26, hai lần 09-27 — #362, #363) mà chưa vào `TRAPS.md`: `dev-task.sh format-file`
  chạy `ruff format` toàn file sau mỗi Edit, trong khi phần lớn repo cố ý viết gọn một dòng (`.pre-commit-config.yaml`
  ghi rõ "chỉ ruff-check, không ruff-format") và CI chỉ `ruff check`. Tiền đề sai nằm ngay trong chú thích hook.
- Sửa: `format-file` chỉ format khi bản trong index đã sạch (`git show :./<file> | ruff format --check
  --stdin-filename <file> -`) hoặc file mới chưa track; ngoài repo hay git lỗi thì bỏ qua. `--stdin-filename` bắt
  buộc — thiếu nó ruff lấy line-length 88 và file sạch như `dast.py` cũng bị coi là bẩn (đo: exit 1 thay vì 0).
- Đo hai chiều: 3 ca mới đỏ trước khi sửa (file gọn bị tách dòng, file ngoài repo bị format, qua chính hook), xanh
  sau khi sửa; ca "file sạch vẫn được format" và "file mới vẫn được format" xanh cả hai chiều (canh chiều ngược).
  Trên repo thật, cùng một dòng thêm vào `orch/guards.py`: bản cũ +52/−23, bản mới +1/−0.
- Người sau KHÔNG được quên: hook chạy bản `dev-task.sh` của **checkout chính** — sửa có hiệu lực sau khi PR merge
  và checkout chính `pull`. Trước đó, sửa file gọn một dòng vẫn phải dùng script thay chuỗi.
